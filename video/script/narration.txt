Hi! We are students, and this is Teleport. It keeps AI agents working, even when the computer they run on shuts down.

AI agents now do long jobs. They read websites, check facts, and fix data for hours. They run on small cloud computers called sandboxes. A sandbox can stop at any moment. Ours shut down after thirty minutes.

When a sandbox stops, the agent forgets everything. The work it did is gone. The money we spent on AI calls is wasted. And if we simply start over, the same result can get saved twice.

So we asked a simple question. What if the agent kept its memory somewhere safe, outside the computer? Then another computer could pick up right where it stopped. We call this teleporting.

Archil makes teleporting possible. Archil gives us one shared disk that every sandbox can open at the same time. Each agent saves its progress to that disk after every step. When a sandbox dies, its hold on the task runs out. Another sandbox notices, reads the saved progress, and keeps going. Archil also runs the sandboxes, and saves a copy of the data before we change anything.

Keenable is how our agents check facts. For every row, an agent searches the web with Keenable and reads the real page. A fix only counts if it points to a page Keenable really found. If there is no proof, a person reviews it instead.

To show teleporting in action, we built a data cleaning tool. You paste a link to any public dataset. A planning agent decides what to check. Then Teleport starts a team of agents, each one in its own sandbox.

Now we turn off a sandbox in the middle of its work. Its task jumps to another sandbox. The new sandbox skips the steps that were already done, and finishes the job.

In one test, fifty agents checked every company in the S and P 500. Halfway through, we replaced every single sandbox. All five hundred and three companies still got checked. We lost zero work, and nothing got saved twice.

Thank you to Archil for the shared disks and sandboxes, to Keenable for web search with sources, and to Casco for hosting us tonight. This is Teleport. Agents that keep going, even when their computer stops.
