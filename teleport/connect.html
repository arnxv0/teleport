Bring your own machine

Any computer that can mount the run's Archil disk can join the swarm: it claims tasks, takes over work from machines that die, and leaves the moment you close the lid — without losing or duplicating anything.

mounted (cloud) joining (your hardware) task resumes from its last checkpoint

How it would work

1

Mount the disk

archil mount on Linux (with --conditional), or the Archil Mac app. The code itself lives on the disk — there is nothing else to install.

2

Run workers

One command starts N workers labelled byo:<hostname>. They show up in Fleet and Swarm 3D as just another machine.

3

Leave anytime

Close the lid and its leases expire. Unfinished tasks teleport back to the cloud and resume from their last checkpoint.

join.sh Preview — not enabled in this demo 
$ curl -s "https://<your-teleport>/join.sh?code=<join-code>" | bash -s -- 4
The trailing 4 is the number of workers to start on this machine.

Why it matters

Use idle hardware

Laptops, on-prem servers and GPUs you already pay for pick up work alongside the cloud sandboxes.

Keep sensitive data local

Run verification inside your own network. Only the results go to the branch.

No new infrastructure

No queue, no cluster. The disk is the coordination layer.

Requires macOS 26+ or Linux with the Archil client. Join codes gate access to the disk token.
